# Frontend - React

Interface web do VENDABOT.

## Instalação

```bash
cd frontend
npm install
npm start
```

## Build

```bash
npm run build
```

## Estrutura

```
src/
├── App.js          # Componente principal
├── pages/          # Páginas da aplicação
├── components/     # Componentes reutilizáveis
└── index.js        # Ponto de entrada
```
